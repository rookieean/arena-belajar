# Android Architecture

1 Linux Kernel = display driver, camera driver, flash memory driver, binder driver, keypad, ...
2 Libraries = surface manager, media framework, SQLite, OpenGL, FreeType, WebKit
3 Android Runtime = Libraries Core, device virtula machine (ada di layer yg sama dgn libraries)
4 Application Framework = Activity manager, window manager, content providers, view system, package manager ..
5 Application = Home, Contacts, Phone, browser ..

# praktik id di android Studio

pas kita naruh string di xml, dia bakal kasih warning karena ini karakter yang gak dikenali,
bisa aja kita abaikan aja, atau string yang kita pakai kita daftarkan ke 
app > src > main > res > values > strings.xml

bisa ketik manual dgn format:
<string name="hint_id">please enter id number</string>

ato shortcutnya dengan:
- buka teks stringnya di file xml
- click pada extract string resource
- isi konfigurasinya, edit nama id, isi value stringnya lalu click tombol
- nanti otomatis akan kesimpan di file strings.xml
