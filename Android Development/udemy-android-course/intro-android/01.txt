# Android Architecture

1 Linux Kernel = display driver, camera driver, flash memory driver, binder driver, keypad, ...
2 Libraries = surface manager, media framework, SQLite, OpenGL, FreeType, WebKit
3 Android Runtime = Libraries Core, device virtula machine (ada di layer yg sama dgn libraries)
4 Application Framework = Activity manager, window manager, content providers, view system, package manager ..
5 Application = Home, Contacts, Phone, browser ..
